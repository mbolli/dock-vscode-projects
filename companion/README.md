# companion/ — VS Code reporter extension

TypeScript / Node VS Code extension. Built in WSL. Writes one `{windowId}.json` per
window to the shared state directory per `../contract/`.

Scaffolded in Group 3 of the kickoff plan. Placement (`"ui"` vs `"workspace"`
`extensionKind`) and the `windowId` source are decided by the Phase 0 probe (Group 1).
